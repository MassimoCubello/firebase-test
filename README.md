# firebase-test
A basic example of displaying data from a Firebase Realtime Database.

## Setup
1. Create a Firebase project and set up a Realtime Database.
2. Replace the Firebase configuration in `index.html` with your project's configuration.
3. Add some data to your Realtime Database under a node called `items` (e.g., `items: { item1: "Item 1", item2: "Item 2" }`).
4. Open `index.html` in a web browser to see the data displayed on the page.

## Technologies Used
- HTML
- JavaScript
- Firebase Realtime Database
